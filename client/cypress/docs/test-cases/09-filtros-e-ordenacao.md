# Filtros e ordenação (observação)

**Pré-condições**
- Usuário autenticado.

**Observação importante**
- Nesta versão pode não haver controles de filtros/ordenacao na UI. Se não houver, teste via API.

**Passos (se houver controles na UI)**
1. Aplicar filtros e/ou alterar a ordenação na interface.
2. Verificar que a listagem reflete os critérios aplicados.

**Resultado esperado**
- Lista atualiza conforme filtros/ordenacao selecionados; caso contrário, verifique os endpoints de API para validar filtros/ordenacao.
