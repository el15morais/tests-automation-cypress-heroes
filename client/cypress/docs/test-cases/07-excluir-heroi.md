# Excluir herói

**Pré-condições**
- Usuário admin autenticado.
- Um herói existente para excluir.

**Passos**
1. Acessar a página de edição do herói.
2. Clicar no botão para excluir o herói.
3. Confirmar a ação quando solicitado.

**Resultado esperado**
- O herói não aparece mais na listagem.
- Backend não retorna o herói ao consultar a API.
