# Editar herói

**Pré-condições**
- Usuário admin autenticado.
- Um herói existente para editar.

**Passos**
1. Acessar a página de edição do herói (pela listagem ou via rota de edição).
2. Alterar os campos desejados (nome, preço, fãs, saves, poderes).
3. Submeter as alterações.

**Resultado esperado**
- Após submissão, a listagem mostra os dados atualizados do herói.
- Backend persiste as alterações.
