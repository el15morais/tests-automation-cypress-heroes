# Upload de imagem do herói

**Pré-condições**
- Usuário autenticado com permissão admin (ou acesso ao formulário de criação/edição).

**Passos**
1. Abrir o formulário de criação ou edição de herói.
2. Selecionar um arquivo de imagem válido no campo de upload.
3. Submeter o formulário.

**Resultado esperado**
- A imagem é exibida no avatar do herói.
- O backend aceita o upload e o arquivo fica disponível quando consultado.
