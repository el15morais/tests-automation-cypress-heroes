# Controle de permissão (UI)

**Pré-condições**
- Duas contas de teste: uma comum e uma com permissão administrativa.

**Passos**
1. Logar com o usuário comum e acessar a listagem de heróis.
2. Verificar que opções de administração (ex.: criar, editar, excluir) não estão disponíveis.
3. Efetuar logout e logar com o usuário admin.
4. Verificar que as opções administrativas estão visíveis e funcionais.

**Resultado esperado**
- Usuários sem permissão não veem nem conseguem usar controles administrativos.
- Usuários admin veem e conseguem utilizar as ações administrativas.
