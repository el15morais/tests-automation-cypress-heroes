# Login com usuário válido

**Pré-condições**
- Aplicação em execução (acesse `/heroes`).
- Conta de teste válida (ex.: test@user.com / pass123) ou disponibilize uma via fixtures/API.

**Passos**
1. Acessar `/heroes` no navegador.
2. Abrir o modal de login através do botão de login no cabeçalho.
3. Preencher o campo de e-mail com o e-mail válido.
4. Preencher o campo de senha com a senha válida.
5. Clicar no botão de entrar (Sign in).

**Resultado esperado**
- Usuário autenticado e modal fechado.
