# Listagem de heróis após login

**Pré-condições**
- Usuário autenticado (veja `01-login-valido.md`).

**Passos**
1. Acessar `/heroes`.
2. Verificar que há pelo menos um herói listado.
3. Dentro do primeiro card, verificar que são exibidos nome, preço, número de fãs e número de saves.

**Resultado esperado**
- Cards de herói renderizados corretamente com nome, preço, fãs e saves visíveis.
- Nenhum erro visível na interface; imagens do avatar são exibidas quando disponíveis.
